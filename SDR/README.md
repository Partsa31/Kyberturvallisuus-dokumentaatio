# SDR

This folder contains software-defined radio (SDR) reference material and a project report about locating vessels using AIS signals.

## What I did

I researched RTL-SDR hardware and software, then worked on a group project receiving AIS broadcasts to observe and locate vessels. The report records the receiver setup and project implementation.

## Materials

- [SDR InfoPaketti.pdf](<SDR%20InfoPaketti.pdf>) — an information package on RTL-SDR hardware and SDR software/tools.
- [SDR projekti botskien paikannus.pdf](<SDR%20projekti%20botskien%20paikannus.pdf>) — a group project report on receiving AIS data and locating vessels.
