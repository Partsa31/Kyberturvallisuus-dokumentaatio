# Palomuurit (Firewalls)

This folder contains firewall coursework and rule examples. Topics include stateless filtering with iptables, stateful policies and VPNs, next-generation firewall content filtering, TLS inspection, web application firewalls, and TCP SYN floods.

## What I did

I completed firewall exercises by defining and checking traffic policies for different network directions and services. I also documented practical work with iptables, stateful firewall and VPN policies, NGFW content filtering and TLS inspection, and WAF protections.

## Materials

- [Stateless Firewall.pdf](<Stateless%20Firewall.pdf>) — a stateless firewall assignment covering ICMP, web access, and network-specific rules.
- [ip tables palomuurisääntöjä.pdf](<ip%20tables%20palomuurisääntöjä.pdf>) — iptables rule examples for forwarded traffic.
- [statefull firewall.pdf](<statefull%20firewall.pdf>) — stateful firewall policies and VPN coursework.
- [NGFW & TLS-inspection.pdf](<NGFW%20&%20TLS-inspection.pdf>) — next-generation firewall content filtering and TLS inspection.
- [waf ja synflood.pdf](<waf%20ja%20synflood.pdf>) — WAF configuration and TCP SYN flood coursework.
