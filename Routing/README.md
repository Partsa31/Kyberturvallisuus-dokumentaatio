# Routing

This folder contains routing and data-center networking exercises, configuration notes, and lab references. Topics include IPv6, OSPF/OSPFv3, IS-IS, BGP, VRFs, VXLAN/EVPN, Layer 2 access, and routing security.

## What I did

I worked through routing and switching labs and recorded device configuration examples for IPv6, OSPF, IS-IS, BGP, VRFs, VXLAN/EVPN, and Layer 2 access. I also completed security-focused exercises involving BGP route threats and Modbus.
