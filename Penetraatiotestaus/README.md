# Penetraatiotestaus (Penetration testing)

This folder contains penetration-testing coursework, lab walkthroughs, and reports. The materials include network and web application exercises, a case-study walkthrough, malware analysis, and work on Active Directory defense and attack scenarios.

## What I did

In coursework and controlled lab environments, I practiced assessing networks and web applications, followed case-study exercises, and documented findings. I also analyzed malware and studied Active Directory attack paths alongside defensive practices, including work in an IPv6 lab.
