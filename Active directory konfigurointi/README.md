# Active Directory configuration

This folder contains Windows domain coursework: a design/configuration document for a sample organization and a separate report on hardening a Windows domain and Active Directory.

## What I did

I planned and documented a sample Windows domain, including its naming, addressing, sites, Group Policy, users, and services. I also researched domain hardening, password practices, and tools used to improve Active Directory security.
