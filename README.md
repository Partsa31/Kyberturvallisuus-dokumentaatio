# Cybersecurity Engineering Portfolio

This repository brings together project reports, lab work, configuration notes, and learning materials from my cybersecurity engineering studies. It shows the areas I have explored so far, from network and infrastructure configuration to security controls, authorized testing exercises, scripting, and virtualization.

The work here is academic and lab-based; it is intended to show practical learning and documentation skills, not to represent professional employment or production deployments.

## What I have worked on

- **Network engineering:** configured and documented switching, VLANs, routing protocols, IPv6, BGP, and data-center networking labs.
- **Infrastructure security:** worked with Active Directory and Windows domain configuration, hardening practices, firewall policies, and network access controls.
- **Security testing and analysis:** completed controlled coursework exercises in penetration testing, malware analysis, and network security.
- **Systems and tools:** documented virtualization environments, an SDR/AIS project, and a scripting project.
- **Technical communication:** produced reports, presentations, topology references, configuration examples, and lab documentation.
